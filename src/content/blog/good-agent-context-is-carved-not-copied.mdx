I've been experimenting with different combinations of AI models and agents for my software development workflows. I had used a lot of browser-based chat for this, but quickly found that this didn’t scale. As the work became more complex, the responses became less predictable and began to drift.

That pushed me toward repo-aware coding agents like Codex, OpenCode, and Pi. Those tools maintain a tighter connection with the project files, inspect actual state of work, and put less distance between conversation and code.

That was a good start, but the results still felt unpredictable.

One agent would make a careful, focused change. Another would rewrite more than I had asked for. One model would recognize an existing project pattern, while another would introduce a new abstraction. The same instruction could be followed exactly or interpreted loosely.

The problem was not simply that one response was right and another was wrong. The same request could produce several plausible interpretations, each based on assumptions I had not realized I was leaving open.

Inconsistency was the symptom. Ambiguity became the challenge.
