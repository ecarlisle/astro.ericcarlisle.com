# Architecture

**Use when:** Changing pages, routes, layouts, components, rendering, integrations, or project structure, or finding where a topic's source of truth lives.

This is an Astro 7 static site. One layout (`BlogPost.astro`) renders every page. Client JavaScript is limited to search, analytics, theme toggle, and tag filter. The contact form runs on a separate Cloudflare Worker.

## Core Areas

| Path | Contents |
|---|---|
| `src/pages/` | Route-level pages |
| `src/content/blog/` | Markdown and MDX posts |
| `src/content.config.ts` | Blog frontmatter schema |
| `src/layouts/BlogPost.astro` | Layout for articles and shared content pages |
| `src/components/` | Reusable Astro components |
| `src/styles/` | Global styles and tokens, component helpers, feed styles, Pagefind overrides |
| `src/lib/` | Utility logic |
| `src/assets/images/` | Source images processed by Astro |
| `public/` | Static assets copied as-is. `public/llms.txt` describes the published site for LLMs, not repository navigation. |
| `contact-worker/` | Contact form Cloudflare Worker |
| `scripts/` | Automation scripts |
| `specs/` | Single-use change specifications (`specs/_template.md`) |
| `.agents/skills/` | Shared agent skills (see [README](../README.md#shared-skills-directory)) |

## Generated Areas

These are regenerated by builds or tools. Never edit them directly:

`dist/` · `node_modules/` · `.astro/` · `storybook-static/` · `lh-reports/` · `docs/context/` · `.playwright-mcp/`

## Notable Integrations

Integrations are configured in `astro.config.mjs` (a protected file):

- MDX, RSS, and sitemap
- Pagefind static search
- Partytown (GA4 runs off the main thread)
- Expressive Code (code blocks)
- Playform Compress (build output)
- Sentry (installed, inert)

External services: GitHub Actions and Pages, Cloudflare Workers and Turnstile, Resend, GA4, and Playwright for testing.

## Architectural Decisions

- [Static-first Astro architecture](decisions/001-static-first-astro-architecture.md): every page renders at build time.
- [Separate Cloudflare Worker for the contact form](decisions/002-separate-cloudflare-worker-for-contact-form.md): the Worker has its own deploy cycle, secrets, and CAPTCHA.
- [Pagefind for static search](decisions/003-pagefind-for-static-site-search.md): the search index is built from static HTML, with no search server.
- [Connected Schema.org graph](decisions/004-connected-schema-org-graph-for-structured-data.md): JSON-LD entities reference each other across page types.
